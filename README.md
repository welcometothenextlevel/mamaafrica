# Mama Africa Beauty — Payerne

Site vitrine (pitch) pour Mama Africa Beauty, salon de coiffure africaine et boutique beauté, Rue de Lausanne 38B, 1530 Payerne.

- Pages générées par `python3 _build/build.py` (données dans `_build/data.py`, gabarits dans `_build/build.py`).
- CSS/JS écrits à la main dans `assets/`. Les scènes 3D (tresse, cauris, peigne afro) sont procédurales : `assets/js/scene.js` (three.js r170 embarqué).
- `PITCH = True` dans `data.py` ajoute `noindex` et bloque `robots.txt`. Passer à `False` à la signature.
- Avis Google : remplacer `REVIEWS` / `REVIEW_PLACEHOLDERS` dans `data.py` au fur et à mesure.
